# 📄 DocAI — PDF Chatbot (RAG with HuggingFace)

An AI-powered chatbot that lets you upload PDFs and ask questions using Retrieval-Augmented Generation (RAG).

## Features
- PDF Q&A chatbot
- FAISS vector search
- HuggingFace embeddings
- Qwen LLM
- Gradio UI

## Setup
Install dependencies:
pip install -r requirements.txt

Run in Colab or local Jupyter.

## Usage
1. Upload PDF
2. Process PDF
3. Ask questions
